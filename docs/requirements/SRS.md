## 1. 引言

### 1.1 编写目的

本文档定义了 CFD-Class 一维溃坝CFD教学软件的完整功能需求、非功能需求和验收标准。

**目标读者**:
- 开发团队 (@BE, @FE, @QA, @TW)
- 测试人员 (@QA)
- 项目管理人员 (@PM)
- 未来可能的维护者

### 1.2 项目背景

一维溃坝问题是计算流体力学(CFD)中的经典教学案例，涉及：
- 浅水方程(Saint-Venant方程组)的推导与求解
- Riemann问题的精确解与数值解对比
- 不同有限体积(FVM)格式在激波捕捉中的表现差异

目前缺乏一款面向教学的、支持多格式交互式对比的标准化软件工具。本项目旨在填补这一空白。

### 1.3 定义与缩写

| 术语/缩写 | 定义 |
|----------|------|
| CFD | Computational Fluid Dynamics, 计算流体力学 |
| FVM | Finite Volume Method, 有限体积法 |
| TVD | Total Variation Diminishing, 总变差衰减 |
| CFL | Courant-Friedrichs-Lewy数, 稳定性条件参数 |
| SWE | Shallow Water Equations, 浅水方程 |
| h | 水深 (water depth), [m] |
| u | 流速 (velocity), [m/s] |
| g | 重力加速度 (gravity), [m/s²], 默认9.81 |
| nx | 网格单元数量 |
| t_end | 终止时间, [s] |
| L1/L2/L∞ | 误差度量范数 |

## 2. 总体描述

### 2.1 产品概述

**产品定位**: 面向具有流体力学基础知识的学生的一维溃坝问题研究演示教学软件

**目标用户**:
- 主要用户: 流体力学/水利工程专业本科生、研究生
- 次要用户: 对CFD感兴趣的零基础学习者

**使用场景**:
- 课堂教学演示（教师使用）
- 自主学习探索（学生使用）
- 课程作业/研究报告辅助（学生使用）

### 2.2 产品功能

本软件包含四大功能模块：

```
┌────────────┬────────────┬────────────┬────────────┐
│   🏠 首页   │   📊 模拟   │   🎬 动画   │   📝 报告   │
│  理论背景   │  参数设置   │ 动态可视化  │  对比分析   │
└────────────┴────────────┴────────────┴────────────┘
```

#### 2.2.1 首页 — 理论背景模块

**功能定位**: 为用户提供一维溃坝问题的完整理论背景知识，建立从物理问题到数值方法的认知桥梁。

**主要子功能**:
- **物理问题描述**: 介绍一维溃坝问题的定义、工程意义（大坝溃决、洪水演进、涌潮预测等），引用至少2个真实工程案例。
- **数学推导展示**: 从Navier-Stokes方程出发，通过尺度分析和深度平均，推导得到浅水方程(Saint-Venant方程组)；展示守恒律的向量形式 U_t + F_x = 0。
- **特征线分析**: 展示特征线方程、特征速度(λ₁=u-c, λ₂=u+c)以及黎曼不变量 R± = u ± 2√(gh)的物理意义。
- **波系结构图解**: 提供四区波系结构（左区、左星区、右星区、右区）的交互式图解，支持点击各区查看详细物理说明和计算公式。
- **数值方法概述**: 提供6种有限体积格式（LF/LW/MC/Godunov/HLL/MUSCL-Hancock）的对比表格，包含精度阶数、TVD稳定性、适用场景和优缺点分析。
- **TVD概念讲解**: 介绍总变差衰减(TVD)概念、Godunov定理以及minmod限制器的工作原理，配合动画演示。
- **参数详解卡片**: 以卡片形式逐一展示8个核心参数（h_L, h_R, u_L, u_R, g, CFL, nx, t_end）的物理意义、取值范围和对结果的影响。
- **学习路径指引**: 提供5步推荐学习路径流程图，从理论学习到报告生成，支持点击跳转对应页面。
- **页面导航卡片**: 以卡片式UI介绍三大功能页面（模拟、动画、报告）的核心功能，支持一键跳转。

**输入**: 用户鼠标点击、页面滚动、交互元素操作。
**处理**: Streamlit页面渲染、LaTeX公式解析、交互状态管理。
**输出**: 渲染后的理论内容页面、展开的详细信息、页面跳转。

#### 2.2.2 模拟 — 参数设置与运行模块

**功能定位**: 核心计算功能入口，支持用户自定义参数、选择数值格式、运行模拟并查看结果对比。

**主要子功能**:
- **物理参数输入面板**: 提供h_L（左侧水深）、h_R（右侧水深）、u_L（左侧流速）、u_R（右侧流速）、g（重力加速度）五个物理参数的输入控件，支持滑块和数字输入双模式。
- **数值参数输入面板**: 提供CFL稳定性数、网格单元数nx、终止时间t_end三个数值参数的输入控件，内置合理范围限制。
- **参数校验与提示**: 当参数超出物理合理范围时，阻止运行并提示具体原因；每个参数旁提供帮助图标，点击展开详细物理说明。
- **预设案例加载**: 提供5组以上经典预设案例（干底Ritter解、湿底一般解、高Froude数、对称扩展、极端干湿等），支持一键加载参数组合。
- **格式选择器**: 提供6种FVM格式的多选框，支持选择1-6种格式进行对比，默认全选。
- **运行控制**: 提供开始/停止/重置按钮，运行过程中显示实时进度条，响应延迟<100ms。
- **精确解显示**: 显示精确Riemann求解器计算的关键物理量（激波速度、稀疏波头尾速度、星区水深和流速），数值保留4位有效数字。
- **结果可视化**: 生成多格式h(x)水深剖面对比图和u(x)速度剖面对比图，数值解与精确解同屏对比。
- **误差统计**: 计算并展示各格式相对于精确解的L1/L2/L∞误差统计表格。
- **质量守恒检查**: 计算并显示质量守恒误差Δm/m₀，提供通过/失败状态指示。
- **结果导出**: 支持PNG图片和CSV数据导出，通过Streamlit下载按钮实现。

**输入**: 用户参数输入（滑块/数字框）、格式选择、按钮点击。
**处理**: 参数校验、DamBreakConfig配置生成、多格式并行/串行计算、误差分析、Matplotlib绑图。
**输出**: 参数配置对象、模拟结果字典、对比图表、误差表格、下载文件。

#### 2.2.3 动画 — 动态可视化模块

**功能定位**: 将静态模拟结果转化为动态可视化内容，帮助用户直观理解溃坝波的时空演化过程。

**主要子功能**:
- **单格式时间演化GIF**: 针对选定的一种数值格式，生成水深h(x)随时间演化的GIF动画，帧率≥15fps。
- **六格式同步对比动画**: 以2×3或3×2子图布局，同步展示6种格式在同一时刻的数值解对比，时间轴同步推进。
- **参数扫描动画**: 连续变化某一物理参数（如h_R从0到1.0），观察解的结构变化，生成≥10帧的动画序列。
- **双变量动画**: 同时展示h(x)和u(x)的时空演化，采用上下双图布局。
- **误差空间演化热力图**: 展示数值解与精确解之间误差在空间和时间上的分布，采用彩色热力图渲染。
- **x-t平面特征线追踪**: 在x-t平面上绘制特征线轨迹，标注激波位置和稀疏波区域。
- **动画参数调节**: 提供FPS、帧数、分辨率等参数的调节滑块，支持实时预览效果。
- **动画导出**: 支持GIF格式下载（文件<5MB）和Streamlit内嵌预览；可选MP4视频导出（需ffmpeg支持，分辨率1080p）。

**输入**: 用户选择的动画类型、格式选择、动画参数（FPS/帧数/分辨率）。
**处理**: 时间序列快照插值、Matplotlib动画帧生成、Pillow GIF编码、可选ffmpeg视频编码。
**输出**: GIF动画文件、MP4视频文件、内嵌预览播放器、下载链接。

#### 2.2.4 报告 — 自动化对比分析模块

**功能定位**: 自动化生成符合学术规范的HTML分析报告，支持收敛性分析、敏感性分析和多格式定量对比。

**主要子功能**:
- **报告配置面板**: 提供参数组合选择、格式选择、网格序列（nx=[50,100,200,400,800]）选择的配置界面。
- **一键HTML报告生成**: 根据配置自动运行多组模拟，生成单文件自包含HTML报告，生成时间<30秒。
- **物理背景自动填充**: 报告自动包含一维溃坝问题的物理背景章节，含LaTeX公式渲染。
- **数值方法自动填充**: 报告自动包含6种FVM格式的数学表达式和原理说明。
- **图表自动生成**: 自动生成≥7张专业对比图表，包括水深/速度剖面、误差对比、收敛性曲线等。
- **数据表格自动生成**: 自动生成≥5张数据表格，包括误差统计、收敛阶、质量守恒检查等。
- **MathJax公式渲染**: HTML报告中所有数学公式采用MathJax渲染，支持离线打开时正常显示。
- **自动文本分析**: 基于模拟数据自动生成通顺专业的分析结论文本，包括各格式优缺点评述和推荐建议。
- **收敛性分析**: 对网格序列执行收敛性测试，生成对数坐标误差-网格尺寸图，并拟合计算收敛阶。
- **参数敏感性分析**: 定量分析各参数对结果的影响程度，生成敏感性热力图。
- **报告模板选择**: 支持简明版（~5页）、详细版（~15页）、学术版（~25页）三种模板。
- **离线下载**: 支持下载单文件自包含HTML报告，无需网络即可正常查看。

**输入**: 用户报告配置（参数/格式/网格序列/模板选择）。
**处理**: 批量模拟运行、误差分析、收敛阶拟合、图表生成、Jinja2模板渲染、MathJax公式注入。
**输出**: 单文件自包含HTML报告、下载链接。

#### FR-05: 核心引擎模块

| FR-05.05 | 透射边界条件处理 | P0 | apply_bc() → U |
| FR-05.06 | 正性保持机制(防止负水深) | P0 | EPS_H = 1e-12 |
| FR-05.07 | 快照记录系统 | P0 | snapshots: Dict[float, ndarray] |

| FR-05.11 | 进度回调接口(用于前端进度条) | P1 | progress_callback: Callable |
| FR-05.12 | 多格式并行计算支持 | P2 | run_parallel() → Dict |

**FR-05.01 详细说明**:
- **输入**: 初始状态U₀（nx×2的ndarray），DamBreakConfig配置对象，终止时间t_end。
- **处理**: 各格式子类（LaxFriedrichsScheme、LaxWendroffScheme、MacCormackScheme、GodunovScheme、HLLScheme、MUSCLHancockScheme）实现统一的evolve()接口，按各自算法推进时间步直到t_end。
- **输出**: snapshots字典，键为时间戳（float），值为该时刻的守恒变量数组（ndarray，形状[nx, 2]）。

**FR-05.02 详细说明**:
- **输入**: 左右初始状态（h_L, u_L, h_R, u_R）和重力加速度g。
- **处理**: 对湿底情况使用Newton迭代求解星区方程；对干底情况使用Ritter解析解；计算波系结构（激波或稀疏波）和各区状态。
- **输出**: 字典，包含波速S_L、S_R、星区水深h_star、星区流速u_star、波系类型标识和各区域状态函数。

**FR-05.03 详细说明**:
- **输入**: 左右状态向量U_L、U_R和重力加速度g。
- **处理**: 计算Roe平均或简单平均得到中间状态，估计左波速S_L和右波速S_R，按HLL公式计算数值通量。
- **输出**: HLL数值通量向量（ndarray，形状[2]）。

**FR-05.04 详细说明**:
- **输入**: 当前时刻的守恒变量数组U和CFL数。
- **处理**: 计算最大波速max(|u|+√(gh))，按公式dt = CFL × dx / max_wave_speed计算时间步长。
- **输出**: 自适应时间步长dt（float）。

**FR-05.05 详细说明**:
- **输入**: 内部网格点的守恒变量数组U。
- **处理**: 在网格边界处设置透射边界条件（零梯度外推），即U[-1]=U[0], U[nx]=U[nx-1]。
- **输出**: 扩展后的守恒变量数组（含ghost cells）。

**FR-05.06 详细说明**:
- **输入**: 推进后的水深数组h。
- **处理**: 遍历水深数组，若h[i] < EPS_H（1e-12），则将其截断为EPS_H，并记录修正日志。
- **输出**: 修正后的水深数组，确保所有h ≥ EPS_H。

**FR-05.07 详细说明**:
- **输入**: 时间步推进过程中的中间状态U和当前时间t。
- **处理**: 按预设的时间采样策略（如每固定时间间隔或固定步数）保存状态副本到字典中。
- **输出**: snapshots字典，记录关键时间点的状态用于后续可视化和动画生成。

**FR-05.08 详细说明**:
- **输入**: 数值解数组u_num、精确解数组u_exact、网格间距dx。
- **处理**: 分别计算L1 = Σ|u_num - u_exact|×dx、L2 = √(Σ(u_num - u_exact)²×dx)、L∞ = max|u_num - u_exact|。
- **输出**: 误差值（float）。

**FR-05.09 详细说明**:
- **输入**: 网格尺寸序列dxs和对应误差序列errors。
- **处理**: 对log(dxs)和log(errors)进行线性拟合（最小二乘法），斜率即为收敛阶p。
- **输出**: 收敛阶估计值p（float）。

**FR-05.10 详细说明**:
- **输入**: 各参数值。
- **处理**: 使用Python的@dataclass(frozen=True)装饰器创建不可变配置对象，所有参数在创建后不可修改，确保数值实验的可重复性。
- **输出**: DamBreakConfig实例，支持属性访问和自动类型检查。

**FR-05.11 详细说明**:
- **输入**: 模拟运行过程中的进度比例（0.0~1.0）。
- **处理**: 在evolve()循环中定期调用progress_callback(progress)函数，将进度信息传递回前端。
- **输出**: 前端进度条状态更新。

**FR-05.12 详细说明**:
- **输入**: 格式列表、DamBreakConfig配置。
- **处理**: 使用Python的concurrent.futures.ProcessPoolExecutor或ThreadPoolExecutor并行执行多种格式的模拟计算。
- **输出**: 字典，键为格式名称，值为对应的snapshots结果。
