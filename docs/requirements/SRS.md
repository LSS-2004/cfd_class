## 1. 引言

### 1.1 编写目的

本文档定义了 CFD-Class 一维溃坝CFD教学软件的完整功能需求、非功能需求和验收标准。

**目标读者**:
- 开发团队 (@BE, @FE, @QA, @TW)
- 测试人员 (@QA)
- 项目管理人员 (@PM)
- 未来可能的维护者

### 1.2 项目背景

一维溃坝问题是计算流体力学(CFD)中的经典教学案例，涉及：
- 浅水方程(Saint-Venant方程组)的推导与求解
- Riemann问题的精确解与数值解对比
- 不同有限体积(FVM)格式在激波捕捉中的表现差异

目前缺乏一款面向教学的、支持多格式交互式对比的标准化软件工具。本项目旨在填补这一空白。

### 1.3 定义与缩写

| 术语/缩写 | 定义 |
|----------|------|
| CFD | Computational Fluid Dynamics, 计算流体力学 |
| FVM | Finite Volume Method, 有限体积法 |
| TVD | Total Variation Diminishing, 总变差衰减 |
| CFL | Courant-Friedrichs-Lewy数, 稳定性条件参数 |
| SWE | Shallow Water Equations, 浅水方程 |
| h | 水深 (water depth), [m] |
| u | 流速 (velocity), [m/s] |
| g | 重力加速度 (gravity), [m/s²], 默认9.81 |
| nx | 网格单元数量 |
| t_end | 终止时间, [s] |
| L1/L2/L∞ | 误差度量范数 |

### 1.4 参考资料

1. GB/T 9385-2008 计算机软件需求规格说明

## 2. 总体描述

### 2.1 产品概述

**产品定位**: 面向具有流体力学基础知识的学生的一维溃坝问题研究演示教学软件

**目标用户**:
- 主要用户: 流体力学/水利工程专业本科生、研究生
- 次要用户: 对CFD感兴趣的零基础学习者

**使用场景**:
- 课堂教学演示（教师使用）
- 自主学习探索（学生使用）
- 课程作业/研究报告辅助（学生使用）

### 2. 产品功能

本软件包含四大功能模块：

```
┌────────────┬────────────┬────────────┬────────────┐
│   🏠 首页   │   📊 模拟   │   🎬 动画   │   📝 报告   │
│  理论背景   │  参数设置   │ 动态可视化  │  对比分析   │
└────────────┴────────────┴────────────┴────────────┘
```

### 2.3 用户特征

| 用户类型 | 技术水平 | 典型任务 |
|---------|---------|---------|
| 学生(有基础) | 了解流体力学基础 | 参数探索、格式对比、报告生成 |
| 学生(零基础) | 无CFD背景 | 学习理论背景、观看动画演示 |
| 教师 | 精通CFD理论 | 课堂演示、案例设计、结果分析 |

### 2.4 运行环境

**硬件要求**:
- CPU: 任意现代处理器（推荐4核以上）
- 内存: ≥4GB RAM
- 硬盘: ≥500MB可用空间
- 显示器: 分辨率≥1366×768

**软件环境**:
- 操作系统: Windows 10/11, macOS 12+, Ubuntu 20.04+
- Python: >= 3.10, < 3.12
- 浏览器: Chrome/Firefox/Edge (最新版, 用于Streamlit Web UI)

### 2.5 设计与实现约束

1. **技术栈约束**: Python + Streamlit + NumPy/Matplotlib
2. **性能约束**: 单次模拟(nx=500网格)运行时间 < 5秒
3. **兼容性约束**: 支持主流桌面浏览器
4. **标准约束**: 符合 GB/T 8567-2006 文档规范
