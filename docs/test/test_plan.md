## 1. 测试策略

### 1.1 测试目标

1. 验证所有P0功能需求的正确实现
2. 确保数值计算的准确性和稳定性
3. 保证代码质量满足团队标准（PEP 8 + 类型注解 + 80%覆盖率）
4. 验证UI交互的流畅性和友好性

### 1.2 测试类型矩阵

| 测试类型 | 范围 | 负责人 | 工具 |
|---------|------|--------|------|
| 单元测试 | 每个函数/类 | @QA | pytest |
| 集成测试 | 模块间协作 | @QA | pytest |
| 性能测试 | 响应时间和资源占用 | @QA | pytest-benchmark |
| 回归测试 | 防止功能退化 | @QA | pytest |
| 手动测试 | UI交互和用户体验 | 全员 | 人工 |

### 1.3 通过标准

| 类别 | 标准 |
|------|------|
| 单元测试通过率 | 100%（必须通过的测试）|
| 代码覆盖率 | ≥ 80%（语句覆盖）|
| P0功能完整性 | 100%实现且可用 |
| 性能响应 | nx=500时单次模拟<5秒 |
| 数值精度 | L∞误差 < 5% (nx=200, 干底Ritter解) |
