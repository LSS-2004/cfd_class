# 快速入门指南

> **目标读者**: 首次使用CFD-Class的用户
> **预计时间**: 10分钟
> **前置要求**: 已完成安装（参见 user_manual.md 第3章）

---

## 30秒极速体验

如果你已经完成了安装，只需3步即可看到第一个结果：

```bash
cd cfd_class
.venv\Scripts\activate    # Windows
streamlit run src/frontend/app.py
```

然后在浏览器打开 http://localhost:8501 ，点击左侧 **"📊 模拟"** → 点击 **"▶ 开始模拟"** → 完成！🎉

## 详细步骤（首次使用）

### Step 1: 启动应用

确保你在正确的目录下并激活了虚拟环境：

```bash
# 进入项目目录
cd D:\APaper\MyClaodeCode\CFD\CFD_class

# 激活虚拟环境（Windows）
.venv\Scripts\activate

# Linux/Mac
# source .venv/bin/activate

# 启动Streamlit应用
streamlit run src/frontend/app.py
```

你应该看到终端输出类似：
```
You can now view your Streamlit app in your browser.
Local URL: http://localhost:8501
Network URL: http://192.168.x.x:8501
```

### Step 3: 运行第一次模拟

1. **点击左侧导航的 "📊 模拟"**

2. **保持默认参数不变**（这是经典的干底Ritter解案例）

   - h_R = 0.0 m （右侧干床）
   - 所有其他参数保持默认值

## 常见启动问题排查

### 问题1: 页面打不开/白屏

**排查步骤**：
1. 检查终端是否有错误信息
2. 确认终端显示 `Local URL: http://localhost:8501`
3. 尝试刷新浏览器页面（F5）
4. 检查是否有其他程序占用了8501端口：
   ```bash
   # Windows
   netstat -ano | findstr :8501
   # Linux/Mac
   lsof -i :8501
   ```
5. 如果端口被占用，可以指定其他端口启动：
   ```bash
   streamlit run src/frontend/app.py --server.port 8502
   ```

**常见原因**：
- 依赖未安装完整 → 运行 `pip install -r requirements.txt` 重试
- 防火墙拦截 → 添加Python/Streamlit到防火墙白名单
- 浏览器缓存问题 → 清除缓存或尝试无痕模式

### 问题2: 模拟按钮点击没反应

**排查步骤**：
1. 向下滚动页面，结果可能显示在下方
2. 检查浏览器控制台(F12 → Console)是否有JavaScript错误
3. 检查终端是否有Python报错信息
4. 确认至少勾选了一种数值格式
5. 尝试减小网格数（nx从200改为100）后重试

### 问题3: 中文显示乱码

**排查步骤**：
1. 确保浏览器编码设置为UTF-8（现代浏览器默认支持）
2. 检查操作系统是否安装了中文字体
3. 在Windows上，确保系统区域设置中"Beta: 使用Unicode UTF-8"已启用（控制面板 → 区域 → 管理 → 更改系统区域设置）

### 问题4: 终端报错 "ModuleNotFoundError"

**排查步骤**：
1. 确认已激活虚拟环境（命令行前缀显示 `(.venv)`）
2. 重新安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 如果某个特定包安装失败，尝试单独安装：
   ```bash
   pip install streamlit numpy matplotlib
   ```

### 问题5: 模拟运行极慢或卡住

**排查步骤**：
1. 检查CPU占用率（任务管理器/活动监视器）
2. 减小网格数 nx（200 → 100 → 50）
3. 减少同时运行的格式数量（只选1-2种）
4. 缩短终止时间 t_end（0.5 → 0.2）
5. 关闭其他占用内存的程序

### 问题6: 浏览器提示 "无法连接到 localhost"

**排查步骤**：
1. 确认Streamlit服务仍在运行（终端窗口未关闭）
2. 尝试使用 `127.0.0.1` 代替 `localhost`：
   ```
   http://127.0.0.1:8501
   ```
3. 检查hosts文件是否正确配置（通常不需要修改）
4. 如果通过SSH远程连接，需要使用SSH端口转发

## 首次运行成功后的建议操作

恭喜你成功运行了第一次模拟！以下是建议的后续操作，帮助你更深入地掌握CFD-Class：

### 立即尝试（5分钟）

1. **切换预设案例**
   - 在模拟页面找到"预设案例"下拉框
   - 依次尝试"湿底一般解"和"高Froude数"
   - 观察不同物理条件下的波系结构变化

2. **对比格式差异**
   - 只勾选 "Lax-Friedrichs" 和 "MUSCL-Hancock"
   - 运行模拟，对比一阶格式和二阶格式的分辨率差异
   - 特别注意激波和稀疏波过渡区的差异

### 短期探索（30分钟）

3. **网格敏感性测试**
   - 固定所有物理参数
   - 依次设置 nx = 50, 100, 200, 400
   - 记录各格式的L2误差，观察误差如何减小
   - 理解"网格加密"与"精度提升"的关系

4. **CFL数实验**
   - 固定 nx = 200
   - 依次设置 CFL = 0.3, 0.5, 0.7, 0.9
   - 观察计算时间和结果稳定性的变化
   - 注意：CFL接近1时计算最快，但可能不稳定

5. **生成你的第一个动画**
   - 进入动画页面
   - 选择"六格式对比"
   - 生成GIF并下载
   - 将GIF插入到课程作业或报告中

### 深度学习（1-2小时）

6. **阅读首页理论背景**
   - 点击左侧"🏠 首页"
   - 仔细阅读"数学基础"和"波系结构"部分
   - 尝试手动推导Riemann不变量

7. **生成完整分析报告**
   - 进入报告页面
   - 选择"详细版"模板
   - 点击生成报告
   - 下载HTML报告并在浏览器中打开
   - 报告包含收敛阶分析，可直接用于课程作业

8. **尝试自定义参数组合**
   - 设置 h_L = 2.0, h_R = 0.5, u_L = 1.0, u_R = -0.5
   - 预测会出现什么波系结构（左稀疏波？右激波？）
   - 运行模拟验证你的预测

### 进阶挑战（可选）

9. **收敛阶验证实验**
   - 使用干底Ritter解（有精确解析解）
   - 运行 nx = 50, 100, 200, 400, 800 的序列
   - 记录L1误差，绘制 log(误差) vs log(nx) 图
   - 计算各格式的实验收敛阶，与理论值对比

10. **格式对比研究**
    - 选择湿底工况（h_R = 0.5）
    - 对比Godunov和HLL在激波位置的分辨率
    - 对比Lax-Wendroff和MUSCL-Hancock在光滑区和间断区的表现
    - 撰写简短的对比分析笔记

## 常见问题

**Q: 页面打不开/白屏？**
A: 检查终端是否有错误信息。常见原因是依赖未安装完整，运行 `pip install -r requirements.txt` 重试。详见上方"常见启动问题排查"章节。

**Q: 模拟按钮点没反应？**
A: 向下滚动页面，结果可能显示在下方。或者检查浏览器控制台(F12)是否有JavaScript错误。

**Q: 中文显示乱码？**
A: 确保浏览器编码设置为UTF-8。现代浏览器默认支持。如果仍有问题，检查系统是否启用了UTF-8支持。

**Q: 我想更深入学习理论，有什么推荐？**
A: 建议阅读软件附带的 [理论指南](./theory_guide.md) 文档，以及用户手册第7章的理论指南部分。此外，推荐阅读 Toro 的《Riemann Solvers and Numerical Methods for Fluid Dynamics》和 LeVeque 的《Finite Volume Methods for Hyperbolic Problems》。
