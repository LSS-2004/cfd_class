# 快速入门指南

> **目标读者**: 首次使用CFD-Class的用户
> **预计时间**: 10分钟
> **前置要求**: 已完成安装（参见 user_manual.md 第3章）

---

## 30秒极速体验

如果你已经完成了安装，只需3步即可看到第一个结果：

```bash
cd cfd_class
.venv\Scripts\activate    # Windows
streamlit run src/frontend/app.py
```

然后在浏览器打开 http://localhost:8501 ，点击左侧 **"📊 模拟"** → 点击 **"▶ 开始模拟"** → 完成！🎉

## 详细步骤（首次使用）

### Step 1: 启动应用

确保你在正确的目录下并激活了虚拟环境：

```bash
# 进入项目目录
cd D:\APaper\MyClaodeCode\CFD\CFD_class

# 激活虚拟环境（Windows）
.venv\Scripts\activate

# Linux/Mac
# source .venv/bin/activate

# 启动Streamlit应用
streamlit run src/frontend/app.py
```

你应该看到终端输出类似：
```
You can now view your Streamlit app in your browser.
Local URL: http://localhost:8501
Network URL: http://192.168.x.x:8501
```

### Step 2: 打开浏览器

在浏览器中访问 **http://localhost:8501**

你将看到CFD-Class的首页界面，包含：
- 左侧导航栏（首页/模拟/动画/报告）
- 主内容区（理论背景介绍）

### Step 3: 运行第一次模拟

1. **点击左侧导航的 "📊 模拟"**

2. **保持默认参数不变**（这是经典的干底Ritter解案例）
   - h_L = 1.0 m （左侧水深）
   - h_R = 0.0 m （右侧干床）
   - 所有其他参数保持默认值

3. **确认已勾选所有6种格式**（默认全选）

4. **点击蓝色的 "▶ 开始模拟" 按钮**

5. **等待进度条完成**（通常5-10秒）

6. **查看结果**：
   - 你应该看到一个包含多条曲线的水深剖面图
   - 蓝色实线是各种格式的数值解
   - 红色虚线是精确解析解
   - 下方有误差统计表格

### Step 4: 尝试修改参数

现在你已经成功运行了第一次模拟，让我们试试修改参数：

1. **找到 "右侧水深 h_R" 的滑块**
2. **将其从 0.0 拖动到 0.5**（从干底变为湿底）
3. **再次点击 "▶ 开始模拟"**
4. **观察结果如何变化**：
   - 波系结构改变（不再有稀疏波扇区接触干底）
   - 可能出现激波（间断）
   - 不同格式的差异更加明显

### Step 5: 查看动画（可选）

1. **点击左侧导航的 "🎬 动画"**
2. **选择 "单格式时间演化"**
3. **选择 "Godunov" 格式**
4. **点击 "🎬 生成动画"**
5. **等待GIF生成完成后预览**

## 常见问题

**Q: 页面打不开/白屏？**
A: 检查终端是否有错误信息。常见原因是依赖未安装完整，运行 `pip install -r requirements.txt` 重试。

**Q: 模拟按钮点没反应？**
A: 向下滚动页面，结果可能显示在下方。或者检查浏览器控制台(F12)是否有JavaScript错误。

**Q: 中文显示乱码？**
A: 确保浏览器编码设置为UTF-8。现代浏览器默认支持。
