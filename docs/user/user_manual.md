## 1. 软件概述

### 1.1 软件简介

CFD-Class 是一款面向流体力学专业学生的一维溃坝问题数值模拟教学软件。通过交互式参数调整、多格式对比、动态可视化等功能，帮助用户深入理解浅水方程的数值求解方法。

### 1.2 功能特点

- ✅ 支持6种经典有限体积格式（LF/LW/MC/Godunov/HLL/MUSCL-Hancock）
- ✅ 参数化交互式探索（水深、流速、网格数、CFL数等）
- ✅ 实时误差分析与精确解对比
- ✅ GIF动画生成与时间演化可视化
- ✅ 一键生成HTML分析报告
- ✅ 完整的理论背景讲解与学习路径指引

## 6. 常见问题 FAQ

### Q1: 安装时出现依赖冲突怎么办？

**A**: 推荐使用虚拟环境（venv），避免污染系统Python环境。如果仍有问题，尝试：
```bash
pip install --upgrade pip
pip install -r requirements.txt --no-deps
```

### Q2: 模拟运行很慢怎么办？

**A**: 尝试以下优化：
- 减小网格数 nx（从200降到100）
- 缩短终止时间 t_end
- 减少同时运行的格式数量
- 关闭不需要的可视化选项

### Q3: 出现负水深错误怎么处理？

**A:** 这是干底工况下的已知数值问题。软件已内置正性保持机制会自动处理。如果仍报错，请检查：
- h_R 是否设置为0（完全干底）
- CFL数是否过大（建议≤0.9）
- 网格是否过粗（建议nx≥50）

### Q4: 如何保存我的模拟结果？

**A**: 当前版本支持：
- 图片导出: 在结果图表区域点击下载按钮
- 数据导出: CSV格式（在模拟页面底部）
- 报告导出: HTML格式（在报告页面）

### Q5: 我不懂流体力学基础能用这个软件吗？

**A:** 可以！首页提供了完整的理论背景讲解，从最基础的连续性假设讲起。建议按"快速开始指南"中的学习路径逐步学习。

### Q6: 为什么Lax-Wendroff格式在激波附近出现振荡？

**A:** Lax-Wendroff是二阶中心型格式，在光滑区域精度高，但在间断（激波）附近会产生非物理振荡（Gibbs现象）。这是因为二阶格式不满足TVD性质。建议在激波问题中使用Godunov、HLL或MUSCL-Hancock格式。

### Q7: CFL数是什么？应该如何选择？

**A:** CFL（Courant-Friedrichs-Lewy）数是时间步长与空间步长的比值，决定数值稳定性。对于显式格式，CFL数必须小于1（通常取0.9）。CFL数越小，时间步长越小，计算越慢但越稳定；CFL数接近1，计算效率高但可能在强间断处不稳定。推荐默认值0.9。

### Q8: 网格数nx对结果有什么影响？

**A:** 网格数决定空间离散精度。nx越大，激波捕捉越锐利，稀疏波分辨率越高，但计算时间近似线性增长。对于教学演示，nx=100~200足够；对于收敛性研究，需要nx=400~800。注意：一阶格式（LF、Godunov）在粗网格上耗散很大，激波会被抹平。

### Q9: 为什么Godunov格式和HLL格式的结果很接近？

**A:** HLL格式是Godunov格式的近似版本。Godunov格式精确求解局部Riemann问题，而HLL格式用双波近似代替精确波系，计算量更小。对于浅水方程的溃坝问题，两者的近似程度很好，因此结果接近。在更复杂的问题（如接触间断）中，差异会更明显。

### Q10: 如何理解误差表格中的L1/L2/L∞范数？

**A:** 
- **L1范数**: 误差的绝对值积分，反映整体误差水平，对局部大误差不敏感
- **L2范数**: 误差的平方积分再开方，兼顾整体和局部误差，最常用
- **L∞范数**: 最大绝对误差，反映最坏位置的误差，对激波位置的误差最敏感

在收敛性分析中，通常观察L1和L2范数随网格加密的变化规律来计算收敛阶。

### Q11: 什么是"干底"和"湿底"？为什么结果差异很大？

**A:** "干底"指h_R=0（右侧无水），"湿底"指h_R>0。干底情况下，稀疏波扇区会延伸到干床位置，形成典型的Ritter解，此时星区水深h*=0，流速u*=2√(gh_L)。湿底情况下，界面处可能形成激波或稀疏波，波系结构更复杂。干底是数值方法的严峻考验，许多格式会出现正性保持问题。

### Q12: MUSCL-Hancock格式中的"minmod"限制器有什么作用？

**A:** minmod是一种TVD限制器，用于在重构阶段限制梯度的大小。它的作用是在光滑区域保持二阶精度，在间断附近自动降为一阶以避免振荡。minmod是最保守的限制器，还有其他选择如superbee、van Leer等，它们在精度和稳定性之间有不同的权衡。

### Q13: 模拟结果与精确解在什么情况下差异最大？

**A:** 差异通常在以下情况最大：
- 激波附近：一阶格式会过度抹平激波，二阶格式可能产生振荡
- 干底前沿：数值格式难以精确捕捉水深趋于0的尖端位置
- 高Froude数流动：非线性效应强，数值误差被放大
- 粗网格：所有格式的分辨率都不足

### Q14: 软件支持自定义初始条件吗？

**A:** 当前版本支持通过左侧和右侧参数设置分片常数初始条件（典型的Riemann问题）。对于更复杂的初始条件（如正弦波、高斯包），需要修改源代码中的初始条件函数。后续版本计划支持用户上传自定义初始条件文件。

### Q15: 为什么有时报告生成会失败或超时？

**A:** 报告生成需要运行大量模拟（网格加密序列），耗时较长。如果超时，请尝试：
- 减少报告模板复杂度（选择"简明版"）
- 在生成报告前先用较少的格式和较小的nx运行一次模拟
- 检查系统内存是否充足（建议8GB以上）

## 7. 理论指南

### 7.1 浅水方程推导（从N-S方程到Saint-Venant方程）

#### 7.1.1 控制方程基础

不可压缩Navier-Stokes方程组：

```
连续性方程:  ∇·u = 0
动量方程:    ∂u/∂t + (u·∇)u = -1/ρ ∇p + ν∇²u + g
```

#### 7.1.2 浅水假设

浅水方程基于以下关键假设：
- 水平特征长度 L 远大于垂直特征长度 H（长波近似）
- 压力沿垂向呈静水分布：p = ρg(η - z)
- 垂直速度远小于水平速度
- 自由面波动是主要研究对象

#### 7.1.3 深度平均与Saint-Venant方程

对N-S方程沿水深方向积分，引入深度平均速度：

```
ū(x,t) = 1/h ∫_{z_b}^{η} u(x,z,t) dz
```

得到一维Saint-Venant方程组（守恒形式）：

```
∂h/∂t + ∂(hu)/∂x = 0
∂(hu)/∂t + ∂(hu² + gh²/2)/∂x = 0
```

写成向量守恒律形式：

```
U_t + F(U)_x = 0
```

其中：

```
U = [h, hu]ᵀ
F(U) = [hu, hu² + gh²/2]ᵀ
```

#### 7.1.4 非守恒形式与特征分析

原始变量形式：

```
∂h/∂t + u ∂h/∂x + h ∂u/∂x = 0
∂u/∂t + u ∂u/∂x + g ∂h/∂x = 0
```

Jacobian矩阵：

```
A = ∂F/∂U = [ 0      1    ]
            [ gh-u²  2u   ]
```

特征值（波速）：

```
λ₁ = u - c,   λ₂ = u + c    （其中 c = √(gh) 为波速）
```

特征线方程：

```
dx/dt = u ± c
```

沿特征线，Riemann不变量保持常数：

```
R⁺ = u + 2c  （沿 C⁺ 特征线：dx/dt = u + c）
R⁻ = u - 2c  （沿 C⁻ 特征线：dx/dt = u - c）
```

### 7.2 Riemann问题详解

#### 7.2.1 问题定义

Riemann问题是指初始条件为左右两个常状态的间断分解问题：

```
U(x,0) = U_L  (x < 0)
U(x,0) = U_R  (x > 0)
```

#### 7.2.2 波系结构

浅水方程的Riemann解由以下基本波组成：

1. **1-稀疏波**（向左传播）：
   - 特征扇区，波头速度 S_L = u_L - c_L
   - 波尾速度 S_HL = u* - c*
   - 沿稀疏波：R⁺ = u + 2c = const

2. **1-激波**（向左传播）：
   - 间断面，满足Rankine-Hugoniot条件
   - 激波速度：S = (q* - q_L) / (h* - h_L)

3. **2-稀疏波**（向右传播）：
   - 特征扇区，波头速度 S_R = u_R + c_R
   - 波尾速度 S_HR = u* + c*

4. **2-激波**（向右传播）：
   - 间断面，激波速度：S = (q_R - q*) / (h_R - h*)

#### 7.2.3 星区状态计算

星区状态 (h*, u*) 通过以下迭代求解：

**情况1：左右均为稀疏波（干底或湿底稀疏）**

```
u* = (R⁺_L + R⁻_R) / 2 = (u_L + u_R)/2 + c_L - c_R
c* = (R⁺_L - R⁻_R) / 4 = (u_L - u_R)/4 + (c_L + c_R)/2
h* = c*² / g
```

**情况2：一侧激波、一侧稀疏波**

需要通过Newton迭代求解非线性方程：

```
f_L(h*) + f_R(h*) + u_R - u_L = 0
```

其中：

```
稀疏波函数: f_k(h) = 2(√(gh_k) - √(gh))   (h ≤ h_k)
激波函数:   f_k(h) = (h - h_k)√(g(h + h_k)/(2hh_k))  (h > h_k)
```

迭代收敛后：

```
u* = (u_L + u_R)/2 + (f_L(h*) - f_R(h*))/2
```

#### 7.2.4 干底Ritter解（经典解析解）

当 h_R = 0, u_L = u_R = 0 时，存在解析解：

```
对于 t > 0：

区域1 (x/t ≤ -c_L):      h = h_L,        u = 0
区域2 (-c_L < x/t ≤ 2c_L): h = (2c_L - x/t)²/(9g),  u = 2(x/t + c_L)/3
区域3 (x/t > 2c_L):       h = 0,          u = 0

其中 c_L = √(gh_L)

星区值：h* = 0, u* = 2c_L = 2√(gh_L)
```

### 7.3 有限体积法原理

#### 7.3.1 基本思想

有限体积法（Finite Volume Method, FVM）将计算域划分为若干控制体（单元），在每个控制体上积分守恒律方程：

```
∫_{x_{i-1/2}}^{x_{i+1/2}} U_t dx + F(U)|_{x_{i+1/2}} - F(U)|_{x_{i-1/2}} = 0
```

定义单元平均值：

```
U_i(t) = 1/Δx ∫_{x_{i-1/2}}^{x_{i+1/2}} U(x,t) dx
```

得到半离散形式：

```
dU_i/dt = -1/Δx (F_{i+1/2} - F_{i-1/2})
```

其中 F_{i+1/2} 是单元界面处的数值通量。

#### 7.3.2 数值通量的核心作用

数值通量 F_{i+1/2} 是FVM的核心，它决定了格式的精度、稳定性和耗散特性。好的数值通量应该：
- 满足守恒性
- 满足一致性：F(U,U) = F(U)
- 满足Lax-Wendroff定理：守恒且一致的格式，若收敛则收敛到弱解
- 满足熵条件：排除非物理解

#### 7.3.3 时间离散

采用显式Euler时间推进：

```
U_i^{n+1} = U_i^n - Δt/Δx (F_{i+1/2}^n - F_{i-1/2}^n)
```

时间步长由CFL条件限制：

```
Δt = σ · Δx / S_max,   S_max = max|u ± c|
```

其中 σ ≤ 1 为CFL数。

### 7.4 六种格式数学原理

#### 7.4.1 Lax-Friedrichs (LF) 格式

```
F_{i+1/2}^{LF} = 1/2 [F(U_i) + F(U_{i+1})] - 1/2 (Δx/Δt)(U_{i+1} - U_i)
```

或等价地写成Lax形式：

```
U_i^{n+1} = 1/2(U_{i-1}^n + U_{i+1}^n) - Δt/(2Δx)(F_{i+1}^n - F_{i-1}^n)
```

**特点**：
- 一阶精度，强稳定性
- 数值耗散大，激波抹平严重
- 无需特征分解，实现简单
- CFL条件：σ ≤ 1

#### 7.4.2 Lax-Wendroff (LW) 格式

基于Taylor展开的二步格式：

```
预测步: U_{i+1/2}^{n+1/2} = 1/2(U_i^n + U_{i+1}^n) - Δt/(2Δx)(F_{i+1}^n - F_i^n)
校正步: U_i^{n+1} = U_i^n - Δt/Δx(F_{i+1/2}^{n+1/2} - F_{i-1/2}^{n+1/2})
```

或Richtmyer两步形式：

```
U_{i+1/2}^{n+1/2} = 1/2(U_i + U_{i+1}) - Δt/(2Δx)(F_{i+1} - F_i)
U_i^{n+1} = U_i^n - Δt/Δx(F(U_{i+1/2}^{n+1/2}) - F(U_{i-1/2}^{n+1/2}))
```

**特点**：
- 二阶精度，光滑区精度高
- 在间断附近产生振荡（不满足TVD）
- 线性稳定性：σ ≤ 1

#### 7.4.3 MacCormack (MC) 格式

预测-校正型两步格式：

```
预测步: U_i^p = U_i^n - Δt/Δx(F_{i+1}^n - F_i^n)
校正步: U_i^c = U_i^n - Δt/2Δx[(F_{i+1}^n - F_i^n) + (F_i^p - F_{i-1}^p)]
```

或等价形式：

```
U_i^* = U_i^n - Δt/Δx(F_{i+1}^n - F_i^n)
U_i^{n+1} = 1/2(U_i^n + U_i^*) - Δt/(2Δx)(F_i^* - F_{i-1}^*)
```

**特点**：
- 二阶精度，预测-校正结构
- 与LW格式类似，在间断处有振荡
- 实现简单，计算效率较高

#### 7.4.4 Godunov 格式

```
F_{i+1/2}^{Godunov} = F(U_{i+1/2}^*(U_i, U_{i+1}))
```

其中 U_{i+1/2}^* 是局部Riemann问题 (U_i, U_{i+1}) 在 x/t=0 处的精确解。

**求解步骤**：
1. 在每个界面 (i+1/2) 构造Riemann问题，左状态 U_i，右状态 U_{i+1}
2. 精确求解Riemann问题，得到星区状态 U*
3. 计算物理通量 F(U*)

**特点**：
- 一阶精度，但间断分辨率高
- 自动满足熵条件（精确Riemann解）
- 计算量大（需迭代求解非线性方程）
- 是激波捕捉方法的基准格式

#### 7.4.5 HLL (Harten-Lax-van Leer) 格式

```
F_{i+1/2}^{HLL} = (S_R F_L - S_L F_R + S_L S_R (U_R - U_L)) / (S_R - S_L)
```

其中波速估计：

```
S_L = min(u_L - c_L, u* - c*)
S_R = max(u_R + c_R, u* + c*)
```

简化估计（Davis估计）：

```
S_L = min(u_L - c_L, u_R - c_R)
S_R = max(u_L + c_L, u_R + c_R)
```

**特点**：
- 一阶精度，Godunov格式的近似
- 无需精确求解Riemann问题，计算量小
- 对接触间断分辨率稍差（忽略中间波）
- 工程实用首选格式

#### 7.4.6 MUSCL-Hancock 格式

MUSCL-Hancock是一种高分辨率TVD格式，包含三个步骤：

**Step 1: 线性重构（MUSCL）**

```
U_i^L = U_i - 1/2 Δx σ_i
U_i^R = U_i + 1/2 Δx σ_i
```

其中 σ_i 是限制后的斜率：

```
σ_i = minmod((U_i - U_{i-1})/Δx, (U_{i+1} - U_i)/Δx)
```

minmod函数定义为：

```
minmod(a,b) = sign(a)·max(0, min(|a|, |b|·sign(a·b)))
```

**Step 2: 半时间步进化（Hancock预测）**

```
U_i^{L,n+1/2} = U_i^L - Δt/(2Δx)(F(U_i^R) - F(U_i^L))
U_i^{R,n+1/2} = U_i^R - Δt/(2Δx)(F(U_i^R) - F(U_i^L))
```

**Step 3: Riemann求解与更新**

```
F_{i+1/2} = F^{HLL}(U_i^{R,n+1/2}, U_{i+1}^{L,n+1/2})
U_i^{n+1} = U_i^n - Δt/Δx(F_{i+1/2} - F_{i-1/2})
```

**特点**：
- 二阶精度（光滑区），一阶（间断附近）
- TVD稳定，无振荡
- 通过限制器自动适应解的光滑性
- 计算量适中，精度与稳定性兼顾

### 7.5 TVD性质与限制器

#### 7.5.1 Godunov定理

**定理**：线性单调格式最高只有一阶精度。

推论：
- 要达到二阶精度，格式必须是非线性的（即使求解线性方程）
- 非线性限制器是实现高分辨率的关键

#### 7.5.2 TVD定义

Total Variation Diminishing（总变差递减）：

```
TV(U^{n+1}) ≤ TV(U^n)
```

其中总变差定义为：

```
TV(U) = Σ |U_{i+1} - U_i|
```

TVD性质保证：
- 不产生新的极值点
- 无虚假振荡
- 单调解保持单调

#### 7.5.3 Harten条件

对于显式守恒格式：

```
U_i^{n+1} = U_i^n - C_{i-1/2}(U_i^n - U_{i-1}^n) + D_{i+1/2}(U_{i+1}^n - U_i^n)
```

TVD的充分条件：

```
C_{i-1/2} ≥ 0,  D_{i+1/2} ≥ 0,  C_{i-1/2} + D_{i+1/2} ≤ 1
```

#### 7.5.4 常见限制器

**minmod限制器**（最保守）：

```
φ(θ) = max(0, min(1, θ))
```

**superbee限制器**（最激进）：

```
φ(θ) = max(0, min(2θ, 1), min(θ, 2))
```

**van Leer限制器**（折中）：

```
φ(θ) = (θ + |θ|) / (1 + |θ|)
```

其中 θ = (U_i - U_{i-1}) / (U_{i+1} - U_i) 是相邻斜率比。

**限制器的作用机制**：
- 当 θ ≈ 1（光滑区）：限制器 ≈ 1，保持二阶精度
- 当 θ → 0 或 θ → ∞（间断附近）：限制器 → 0，降为一阶以避免振荡

### 7.6 误差分析与收敛阶

#### 7.6.1 误差度量

对于数值解 U_h 和精确解 U_exact：

**L1范数误差**：

```
E_1 = Δx Σ |U_h(x_i) - U_exact(x_i)|
```

**L2范数误差**：

```
E_2 = √(Δx Σ |U_h(x_i) - U_exact(x_i)|²)
```

**L∞范数误差**：

```
E_∞ = max_i |U_h(x_i) - U_exact(x_i)|
```

#### 7.6.2 收敛阶定义

当网格加密时（Δx → 0），误差按幂律减小：

```
E ≈ C · Δx^p
```

其中 p 为收敛阶，C 为常数。

通过两组网格的误差计算收敛阶：

```
p = log(E_{h1}/E_{h2}) / log(h1/h2)
```

#### 7.6.3 各格式的理论收敛阶

| 格式 | 光滑区收敛阶 | 间断附近收敛阶 | 备注 |
|------|-------------|---------------|------|
| Lax-Friedrichs | 1 | 1 | 全局一阶 |
| Lax-Wendroff | 2 | ~1 | 间断处振荡 |
| MacCormack | 2 | ~1 | 同LW |
| Godunov | 1 | 1 | 激波处一阶 |
| HLL | 1 | 1 | 同Godunov |
| MUSCL-Hancock | 2 | 1 | TVD自适应 |

#### 7.6.4 数值实验验证收敛阶

在软件中，通过网格加密序列（nx = 50, 100, 200, 400, 800）可以实验验证收敛阶：

1. 固定物理参数和终止时间
2. 依次运行不同网格数的模拟
3. 记录各格式的L1/L2误差
4. 绘制误差-网格数双对数图
5. 拟合斜率得到实验收敛阶

对于一阶格式，期望斜率 ≈ -1（即 p ≈ 1）
对于二阶格式，期望斜率 ≈ -2（即 p ≈ 2）

**注意**：在含间断的问题中，即使格式在光滑区是二阶的，全局收敛阶通常也退化为一阶。这是因为间断附近的误差主导了整体误差。
