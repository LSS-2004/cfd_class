## 1. 软件概述

### 1.1 软件简介

CFD-Class 是一款面向流体力学专业学生的一维溃坝问题数值模拟教学软件。通过交互式参数调整、多格式对比、动态可视化等功能，帮助用户深入理解浅水方程的数值求解方法。

### 1.2 功能特点

- ✅ 支持6种经典有限体积格式（LF/LW/MC/Godunov/HLL/MUSCL-Hancock）
- ✅ 参数化交互式探索（水深、流速、网格数、CFL数等）
- ✅ 实时误差分析与精确解对比
- ✅ GIF动画生成与时间演化可视化
- ✅ 一键生成HTML分析报告
- ✅ 完整的理论背景讲解与学习路径指引

## 3. 安装步骤

### 3.1 方式一：从源码安装（推荐开发者使用）

```bash
# Step 1: 克隆仓库
git clone https://github.com/kaklos-cyber/cfd_class.git
cd cfd_class

# Step 2: 创建虚拟环境
python -m venv .venv

# Step 3: 激活虚拟环境
# Windows:
.venv\Scripts\activate
# Linux/Mac:
source .venv/bin/activate

# Step 4: 安装依赖
pip install -r requirements.txt

# Step 5: 启动应用
streamlit run src/frontend/app.py
```

### 3.2 方式二：使用安装包（面向普通用户）

```bash
# 下载发布包（待后续版本提供）
# pip install cfd-class

# 启动应用
cfd-class
```

### 3.3 验证安装成功

启动后在浏览器访问 `http://localhost:8501`，如果看到CFD-Class首页界面，说明安装成功。

### 5.2 📊 模拟 — 参数设置与运行

#### 参数面板说明

**物理参数（左侧面板）**：

| 参数 | 符号 | 默认值 | 范围 | 物理含义 |
|------|------|-------|------|---------|
| 左侧水深 | h_L | 1.0 m | [0.1, 10.0] | 大坝左侧初始水位 |
| 右侧水深 | h_R | 0.0 m | [0.0, 10.0] | 大坝右侧初始水位(0=干底) |
| 左侧流速 | u_L | 0.0 m/s | [-5.0, 5.0] | 左侧水体初速度 |
| 右侧流速 | u_R | 0.0 m/s | [-5.0, 5.0] | 右侧水体初速度 |
| 重力加速度 | g | 9.81 m/s² | [0.1, 20.0] | 重力场强度 |

**数值参数（右侧面板）**：

| 参数 | 符号 | 默认值 | 范围 | 含义 |
|------|------|-------|------|------|
| CFL数 | σ | 0.9 | [0.1, 0.95] | 时间步长稳定性系数 |
| 网格数 | nx | 200 | [50, 2000] | 空间离散单元数量 |
| 终止时间 | t_end | 0.5 s | [0.1, 10.0] | 模拟总时长 |

#### 操作步骤

1. **设置参数**: 使用滑块或直接输入数值
2. **选择格式**: 勾选要运行的格式（默认全选6种）
3. **加载预设**（可选）: 点击"预设案例"下拉框选择经典案例
4. **开始运行**: 点击"▶ 开始模拟"按钮
5. **查看结果**:
   - 水深剖面对比图（h(x)曲线）
   - 速度剖面对比图（u(x)曲线）
   - 误差统计表格（L1/L2/L∞范数）
   - 精确解关键量显示

#### 结果解读

- **蓝色实线**: 数值解
- **红色虚线**: 精确解析解（参考基准）
- **表格颜色标记**: 绿色=最优，黄色=中等，红色=较差

## 6. 常见问题 FAQ

### Q1: 安装时出现依赖冲突怎么办？

**A**: 推荐使用虚拟环境（venv），避免污染系统Python环境。如果仍有问题，尝试：
```bash
pip install --upgrade pip
pip install -r requirements.txt --no-deps
```

### Q2: 模拟运行很慢怎么办？

**A**: 尝试以下优化：
- 减小网格数 nx（从200降到100）
- 缩短终止时间 t_end
- 减少同时运行的格式数量
- 关闭不需要的可视化选项

### Q3: 出现负水深错误怎么处理？

**A:** 这是干底工况下的已知数值问题。软件已内置正性保持机制会自动处理。如果仍报错，请检查：
- h_R 是否设置为0（完全干底）
- CFL数是否过大（建议≤0.9）
- 网格是否过粗（建议nx≥50）

### Q4: 如何保存我的模拟结果？

**A**: 当前版本支持：
- 图片导出: 在结果图表区域点击下载按钮
- 数据导出: CSV格式（在模拟页面底部）
- 报告导出: HTML格式（在报告页面）

### Q5: 我不懂流体力学基础能用这个软件吗？

**A:** 可以！首页提供了完整的理论背景讲解，从最基础的连续性假设讲起。建议按"快速开始指南"中的学习路径逐步学习。

### C. 错误代码说明

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| ConfigValidationError | 参数超出范围 | 检查参数范围限制提示 |
| NumericalInstabilityError | 数值不稳定 | 降低CFL数或增加粘性 |
| ConvergenceError | Riemann求解器不收敛 | 通常自动回退到HLL |
| PositiveDepthViolation | 出现负水深 | 软件自动修正，可忽略 |
