## 1. 浅水方程

### 1.1 物理背景

浅水方程（Shallow Water Equations, SWE）描述的是具有自由表面的薄层流体运动。"浅水"意味着流体的水平尺度远大于垂直尺度，这使得垂直方向的加速度可以忽略，压力沿垂向呈静水分布。

**典型应用场景**：
- 河流、渠道中的洪水演进
- 大坝溃决后的涌波传播
- 沿海地区的潮汐和风暴潮
- 大气中的大尺度流动（简化模型）

### 1.2 从Navier-Stokes方程出发

不可压缩流体的Navier-Stokes方程组为：

```
连续性方程:
∂u/∂x + ∂v/∂y + ∂w/∂z = 0

x方向动量方程:
∂u/∂t + u∂u/∂x + v∂u/∂y + w∂u/∂z = -1/ρ ∂p/∂x + ν∇²u

z方向动量方程:
∂w/∂t + u∂w/∂x + v∂w/∂y + w∂w/∂z = -1/ρ ∂p/∂z - g + ν∇²w
```

**浅水假设**：
1. 垂直速度 w 远小于水平速度 u
2. 垂直加速度项 ∂w/∂t + ... 可忽略
3. 粘性效应在垂直方向通过底摩擦参数化

由z方向动量方程的简化形式：

```
0 = -1/ρ ∂p/∂z - g
```

积分得到**静水压力分布**：

```
p(x,z,t) = ρg(η(x,t) - z)
```

其中 η(x,t) 是自由面高度，z 是垂直坐标（向上为正）。

### 1.3 深度平均过程

定义**水深**和**深度平均速度**：

```
h(x,t) = η(x,t) - z_b(x)

ū(x,t) = 1/h ∫_{z_b}^{η} u(x,z,t) dz
```

对连续性方程沿水深积分：

```
∫_{z_b}^{η} (∂u/∂x + ∂w/∂z) dz = 0

→ ∂/∂x ∫ u dz + w|_{z=η} - w|_{z=z_b} = 0

→ ∂(hū)/∂x + ∂η/∂t + u_b ∂z_b/∂x = 0
```

利用Leibniz积分法则和自由面运动学边界条件，最终得到：

```
∂h/∂t + ∂(hū)/∂x = 0
```

对x方向动量方程沿水深积分，经过类似推导（忽略粘性项和底摩擦），得到：

```
∂(hū)/∂t + ∂(hū² + gh²/2)/∂x = 0
```

### 1.4 守恒形式与原始变量形式

**守恒形式**（向量形式）：

```
∂U/∂t + ∂F(U)/∂x = 0

其中:
U = [ h    ]      F(U) = [   hu        ]
    [ hu   ]             [ hu² + gh²/2 ]
```

**原始变量形式**（非守恒形式）：

```
∂h/∂t + u ∂h/∂x + h ∂u/∂x = 0
∂u/∂t + u ∂u/∂x + g ∂h/∂x = 0
```

写成矩阵形式：

```
∂/∂t [h]   [ u   h ] ∂/∂x [h]   [0]
     [u] + [ g   u ]      [u] = [0]
```

**重要区别**：守恒形式在激波（间断）处仍然成立，而原始变量形式在间断处失效。因此数值计算中必须使用守恒形式。

### 1.5 物理量的含义

| 变量 | 符号 | 物理意义 | 单位 |
|------|------|---------|------|
| 水深 | h | 自由面到河床的距离 | m |
| 流速 | u | 深度平均的水平速度 | m/s |
| 单宽流量 | q = hu | 单位宽度的体积流量 | m²/s |
| 重力加速度 | g | 地球引力场强度 | m/s² |
| 波速 | c = √(gh) | 浅水重力波的传播速度 | m/s |
| Froude数 | Fr = u/c | 惯性力与重力之比 | 无量纲 |

**Froude数的物理意义**：
- Fr < 1：亚临界流，扰动可向上游传播
- Fr = 1：临界流
- Fr > 1：超临界流，扰动不能向上游传播

## 2. 特征线分析

### 2.1 特征值的物理意义

Jacobian矩阵：

```
A = ∂F/∂U = [ 0        1     ]
            [ gh-u²    2u    ]
```

特征值：

```
λ₁ = u - √(gh) = u - c
λ₂ = u + √(gh) = u + c
```

**物理解释**：
- λ₁ = u - c：左行波速度（流体速度减去波速）
- λ₂ = u + c：右行波速度（流体速度加上波速）

在亚临界流（Fr < 1）时，λ₁ < 0 < λ₂，信息同时向左右传播。
在超临界流（Fr > 1）时，两个特征值同号，信息只向一个方向传播。

### 2.2 特征向量与特征关系

右特征向量：

```
r₁ = [ 1   ]      r₂ = [ 1   ]
     [ u-c ]           [ u+c ]
```

左特征向量（通过 l_k · r_j = δ_kj 求得）：

```
l₁ = 1/(2c) [ u+c  -1 ]
l₂ = 1/(2c) [ c-u   1 ]
```

### 2.3 Riemann不变量

沿特征线，某些组合量保持不变，称为Riemann不变量。

将原始变量方程用特征向量展开，得到：

```
沿 C⁺ 特征线 (dx/dt = u + c):  d/dt(u + 2c) = 0
沿 C⁻ 特征线 (dx/dt = u - c):  d/dt(u - 2c) = 0
```

因此Riemann不变量为：

```
R⁺ = u + 2√(gh)   （沿右行特征线保持不变）
R⁻ = u - 2√(gh)   （沿左行特征线保持不变）
```

**物理意义**：Riemann不变量代表了沿特征线传播的信息。在简单波区域（只有一个波族活跃），一个Riemann不变量在整个区域保持常数。

### 2.4 特征线图示

```
        t
        ▲
        │    ╱  C⁺ 特征线 (dx/dt = u+c)
        │   ╱
        │  ╱
        │ ╱
        │╱  初始间断点 (x=0)
        ├─────────────────────▶ x
        │＼
        │ ＼  C⁻ 特征线 (dx/dt = u-c)
        │  ＼
```

在溃坝问题中，初始间断分解后：
- 左行稀疏波：C⁻ 特征线呈扇形展开
- 右行稀疏波或激波：取决于左右状态

## 3. Riemann问题

### 3.1 问题定义

Riemann问题是双曲型守恒律的最基本初值问题：

```
∂U/∂t + ∂F(U)/∂x = 0,   t > 0

U(x,0) = { U_L,  x < 0
         { U_R,  x > 0
```

物理上对应：两个不同状态的流体在 t=0 时刻被隔板分开，突然抽去隔板后的演化。

### 3.2 波系结构

浅水方程的Riemann解由以下基本波组成（从左侧到右侧）：

**1-波族**（与λ₁ = u-c 相关，向左传播）：
- **1-稀疏波**：连续过渡，特征扇区
- **1-激波**：间断跳跃，满足Rankine-Hugoniot条件

**2-波族**（与λ₂ = u+c 相关，向右传播）：
- **2-稀疏波**：连续过渡，特征扇区
- **2-激波**：间断跳跃，满足Rankine-Hugoniot条件

中间状态 U* = (h*, u*) 连接左右两个波。

### 3.3 激波条件（Rankine-Hugoniot）

激波是解的间断面，必须满足守恒律的跳跃条件：

```
S(U_R - U_L) = F(U_R) - F(U_L)
```

其中 S 是激波速度。

对于浅水方程，具体形式为：

```
质量守恒:  S(h_R - h_L) = h_R u_R - h_L u_L
动量守恒:  S(h_R u_R - h_L u_L) = (h_R u_R² + gh_R²/2) - (h_L u_L² + gh_L²/2)
```

由质量守恒得激波速度：

```
S = (h_R u_R - h_L u_L) / (h_R - h_L)
```

### 3.4 稀疏波（膨胀波）

稀疏波是自相似解，在 (x,t) 平面上呈扇形分布：

```
U(x,t) = U(ξ),   ξ = x/t
```

对于1-稀疏波（左行）：
- 波头速度：S_L = u_L - c_L
- 波尾速度：S* = u* - c*
- 沿稀疏波：R⁺ = u + 2c = u_L + 2c_L = 常数

由R⁺不变量：

```
u + 2c = u_L + 2c_L
```

结合特征线速度 ξ = u - c，可以解出稀疏波内的状态分布：

```
c(ξ) = (u_L + 2c_L - ξ)/3
u(ξ) = (2ξ + u_L + 2c_L)/3
h(ξ) = c(ξ)²/g
```

### 3.5 星区状态求解

星区状态 (h*, u*) 的确定是Riemann问题的核心。

**通量函数定义**：

```
对于k侧（k = L或R）:

若 h* ≤ h_k（稀疏波）:
  f_k(h*) = 2(√(gh_k) - √(gh*))

若 h* > h_k（激波）:
  f_k(h*) = (h* - h_k)√(g(h* + h_k)/(2h*h_k))
```

**星区速度**：

```
u* = (u_L + u_R)/2 + (f_L(h*) - f_R(h*))/2
```

h* 通过求解非线性方程得到：

```
f_L(h*) + f_R(h*) + u_R - u_L = 0
```

通常使用Newton迭代法求解。

### 3.6 干底Ritter解析解

当 h_R = 0, u_L = u_R = 0 时，存在经典解析解：

```
对于 t > 0:

区域1 (x/t ≤ -√(gh_L)):
  h = h_L,  u = 0

区域2 (-√(gh_L) < x/t ≤ 2√(gh_L)):
  h = (2√(gh_L) - x/t)² / (9g)
  u = 2(x/t + √(gh_L)) / 3

区域3 (x/t > 2√(gh_L)):
  h = 0,  u = 0
```

**星区值**：

```
h* = 0
u* = 2√(gh_L)
```

**物理图像**：
- 左侧：静止的高水位区
- 中间：向左传播的稀疏波扇区，水深从h_L渐变到0
- 右侧：干床，无水

## 4. 有限体积法

### 4.1 基本思想

有限体积法（Finite Volume Method, FVM）是求解守恒律方程的最自然数值方法。其核心思想是：

1. 将计算域划分为若干控制体（单元）
2. 在每个控制体上积分守恒律方程
3. 用单元平均值作为基本未知量
4. 通过数值通量计算单元间的质量/动量交换

### 4.2 半离散形式推导

在单元 [x_{i-1/2}, x_{i+1/2}] 上积分守恒律：

```
∫_{x_{i-1/2}}^{x_{i+1/2}} ∂U/∂t dx + ∫_{x_{i-1/2}}^{x_{i+1/2}} ∂F/∂x dx = 0
```

由Leibniz法则和Newton-Leibniz公式：

```
d/dt ∫ U dx + F(U)|_{x_{i+1/2}} - F(U)|_{x_{i-1/2}} = 0
```

定义单元平均值：

```
U_i(t) = 1/Δx ∫_{x_{i-1/2}}^{x_{i+1/2}} U(x,t) dx
```

得到半离散守恒形式：

```
dU_i/dt = -1/Δx (F_{i+1/2} - F_{i-1/2})
```

### 4.3 数值通量的关键作用

数值通量 F_{i+1/2} 近似真实的物理通量 F(U(x_{i+1/2}, t))，是FVM的核心。

**数值通量的基本要求**：
1. **守恒性**：F_{i+1/2} 对左右单元贡献大小相等、方向相反
2. **一致性**：F(U, U) = F(U)（连续情况下恢复物理通量）
3. **Lipschitz连续性**：保证数值稳定性

**数值通量的构造方式**：
- 中心型格式：对称地使用左右状态
- 迎风格式：根据特征方向选择信息来源
- Godunov型格式：求解局部Riemann问题

### 4.4 时间离散与CFL条件

采用显式Euler时间推进：

```
U_i^{n+1} = U_i^n - Δt/Δx (F_{i+1/2}^n - F_{i-1/2}^n)
```

**CFL条件**（稳定性必要条件）：

```
Δt ≤ Δx / S_max
```

其中 S_max = max|λ| = max|u ± c| 是最大波速。

实际计算中：

```
Δt = σ · Δx / S_max,   0 < σ ≤ 1
```

σ 称为CFL数，通常取 0.8 ~ 0.9。

**CFL条件的物理意义**：
数值依赖域必须包含物理依赖域。即在一个时间步内，信息传播的距离不能超过一个网格间距。

## 5. 数值格式详解

### 5.1 格式分类框架

```
数值格式
├── 中心型格式
│   ├── Lax-Friedrichs (LF)
│   ├── Lax-Wendroff (LW)
│   └── MacCormack (MC)
└── Godunov型格式 (迎风格式)
    ├── Godunov (精确Riemann解)
    ├── HLL (近似Riemann解)
    └── MUSCL-Hancock (高分辨率TVD)
```

### 5.2 Lax-Friedrichs格式

**数值通量**：

```
F_{i+1/2}^{LF} = 1/2 [F(U_i) + F(U_{i+1})] - 1/2 (Δx/Δt)(U_{i+1} - U_i)
```

**等价形式**（Lax格式）：

```
U_i^{n+1} = 1/2(U_{i-1}^n + U_{i+1}^n) - Δt/(2Δx)(F_{i+1}^n - F_{i-1}^n)
```

**推导思路**：
- 中心差分 + 人工粘性项
- 人工粘性系数 α = Δx/Δt，刚好保证稳定性

**特点**：
- 一阶精度 O(Δx, Δt)
- 强稳定性，无条件满足CFL条件（σ ≤ 1）
- 数值耗散大，激波被严重抹平（约跨越10-20个网格）
- 实现最简单，无需特征分解

**适用场景**：教学演示、基准对比、极不稳定问题的初步计算

### 5.3 Lax-Wendroff格式

**推导思路**：
基于Taylor展开的时间-空间耦合格式：

```
U(t+Δt) ≈ U + Δt U_t + Δt²/2 U_tt
```

利用守恒律 U_t = -F_x 和 U_tt = (A F_x)_x，得到：

**Richtmyer两步形式**：

```
预测步:
  U_{i+1/2}^{n+1/2} = 1/2(U_i^n + U_{i+1}^n) - Δt/(2Δx)(F_{i+1}^n - F_i^n)

校正步:
  U_i^{n+1} = U_i^n - Δt/Δx(F_{i+1/2}^{n+1/2} - F_{i-1/2}^{n+1/2})
```

**特点**：
- 二阶精度 O(Δx², Δt²)
- 光滑区域精度高
- **在间断附近产生非物理振荡**（Gibbs现象）
- 不满足TVD性质
- 线性稳定性：σ ≤ 1

**物理解释**：
二阶精度意味着格式使用了更宽的信息模板，在间断处"看到"了不该看到的信息，导致振荡。

### 5.4 MacCormack格式

**预测-校正形式**：

```
预测步:
  U_i^p = U_i^n - Δt/Δx(F_{i+1}^n - F_i^n)

校正步:
  U_i^{n+1} = 1/2(U_i^n + U_i^p) - Δt/(2Δx)(F_i^p - F_{i-1}^p)
```

**特点**：
- 二阶精度，与LW格式等价（线性问题）
- 预测步用向前差分，校正步用向后差分
- 同样存在间断振荡问题
- 计算效率略高（无需半步值存储）

### 5.5 Godunov格式

**核心思想**：在每个单元界面求解精确的Riemann问题。

**数值通量**：

```
F_{i+1/2}^{Godunov} = F(U_{i+1/2}^*(U_i, U_{i+1}))
```

其中 U_{i+1/2}^* 是局部Riemann问题在 x/t = 0 处的精确解。

**算法步骤**：
1. 在每个界面 (i+1/2) 构造Riemann问题，左状态 U_i，右状态 U_{i+1}
2. 判断波系类型（稀疏波/激波）
3. 通过Newton迭代求解星区水深 h*
4. 计算星区速度 u*
5. 根据 x/t = 0 的位置确定界面状态
6. 计算物理通量 F(U*)

**特点**：
- 一阶精度
- 间断分辨率高（激波跨越2-3个网格）
- 自动满足熵条件（精确解排除非物理解）
- 计算量大（每步需迭代求解非线性方程）
- 是激波捕捉方法的"黄金标准"

### 5.6 HLL格式

**核心思想**：用双波近似代替精确Riemann解中的多波结构。

**假设**：
- 波系由左波（速度 S_L）和右波（速度 S_R）组成
- 两波之间是常数状态 U_HLL

**数值通量**：

```
F_{i+1/2}^{HLL} = (S_R F_L - S_L F_R + S_L S_R (U_R - U_L)) / (S_R - S_L)
```

**波速估计**（Davis估计）：

```
S_L = min(u_L - c_L, u_R - c_R)
S_R = max(u_L + c_L, u_R + c_R)
```

更精确的Einfeldt估计：

```
S_L = min(u_L - c_L, ũ - c̃)
S_R = max(u_R + c_R, ũ + c̃)
```

其中 (ũ, c̃) 是Roe平均状态。

**特点**：
- 一阶精度
- 无需迭代求解非线性方程，计算量小
- 对接触间断分辨率稍差（忽略了中间波）
- 对浅水方程效果良好（无接触间断）
- 工程实用首选

### 5.7 MUSCL-Hancock格式

MUSCL-Hancock是一种**高分辨率TVD格式**，结合了：
- MUSCL（Monotone Upstream-Centered Schemes for Conservation Laws）重构
- Hancock预测步
- 近似Riemann求解器（如HLL）

**Step 1: 线性重构（MUSCL）**

在单元内构造线性分布：

```
U_i(x) = U_i + σ_i (x - x_i)
```

其中 σ_i 是限制后的斜率：

```
σ_i = minmod((U_i - U_{i-1})/Δx, (U_{i+1} - U_i)/Δx)
```

单元边界值：

```
U_i^L = U_i - 1/2 Δx σ_i    （左边界）
U_i^R = U_i + 1/2 Δx σ_i    （右边界）
```

**Step 2: Hancock预测步**

将边界值推进半个时间步：

```
U_i^{L,n+1/2} = U_i^L - Δt/(2Δx)(F(U_i^R) - F(U_i^L))
U_i^{R,n+1/2} = U_i^R - Δt/(2Δx)(F(U_i^R) - F(U_i^L))
```

**Step 3: Riemann求解与更新**

```
F_{i+1/2} = F^{HLL}(U_i^{R,n+1/2}, U_{i+1}^{L,n+1/2})

U_i^{n+1} = U_i^n - Δt/Δx(F_{i+1/2} - F_{i-1/2})
```

**特点**：
- 光滑区二阶精度，间断附近自动降为一阶
- TVD稳定，无振荡
- 通过限制器自适应地调整精度
- 计算量适中（比Godunov快，比LF/LW慢）
- 综合性能最佳

## 6. TVD与限制器

### 6.1 Godunov定理

**定理**：线性单调格式最高只有一阶精度。

**推论**：
- 要达到二阶精度，格式必须是非线性的（即使求解线性方程）
- 非线性限制器是实现高分辨率的关键技术

### 6.2 TVD的定义与意义

**总变差**（Total Variation）：

```
TV(U) = Σ_{i} |U_{i+1} - U_i|
```

**TVD性质**：

```
TV(U^{n+1}) ≤ TV(U^n)
```

**为什么TVD重要？**
- 不产生新的极值点（无虚假振荡）
- 单调解保持单调
- 保证数值解的物理合理性

### 6.3 Harten的TVD充分条件

对于显式守恒格式：

```
U_i^{n+1} = U_i^n - C_{i-1/2}(U_i^n - U_{i-1}^n) + D_{i+1/2}(U_{i+1}^n - U_i^n)
```

TVD的充分条件：

```
C_{i-1/2} ≥ 0,  D_{i+1/2} ≥ 0,  C_{i-1/2} + D_{i+1/2} ≤ 1
```

### 6.4 限制器函数

限制器通过限制重构斜率来实现TVD性质。

定义斜率比：

```
θ_i = (U_i - U_{i-1}) / (U_{i+1} - U_i)
```

**minmod限制器**（最保守）：

```
φ(θ) = max(0, min(1, θ))
```

特点：最稳定，但精度损失最大。

**superbee限制器**（最激进）：

```
φ(θ) = max(0, min(2θ, 1), min(θ, 2))
```

特点：压缩性最强，但可能在某些情况下过度压缩。

**van Leer限制器**（折中）：

```
φ(θ) = (θ + |θ|) / (1 + |θ|)
```

特点：平滑过渡，综合性能较好。

### 6.5 限制器的作用机制

| 区域类型 | θ值 | 限制器行为 | 效果 |
|---------|-----|-----------|------|
| 光滑区 | θ ≈ 1 | φ ≈ 1 | 保持二阶精度 |
| 极值点附近 | θ < 0 | φ = 0 | 降为一阶，保护极值 |
| 间断附近 | θ → 0 或 ∞ | φ → 0 | 降为一阶，避免振荡 |

```
限制器函数图像示意:

φ(θ)
  ▲
2 │      ╱
  │     ╱
1 │────╱      ← minmod
  │   ╱╲
  │  ╱  ╲     ← van Leer
  │ ╱    ╲
  │╱      ╲   ← superbee
  └───────────▶ θ
    0    1    2
```

## 7. 收敛性分析

### 7.1 误差度量

对于数值解 U_h 和精确解 U_exact：

**L1范数**（平均绝对误差）：

```
||E||_1 = Δx Σ_i |U_h(x_i) - U_exact(x_i)|
```

**L2范数**（均方根误差）：

```
||E||_2 = √(Δx Σ_i |U_h(x_i) - U_exact(x_i)|²)
```

**L∞范数**（最大误差）：

```
||E||_∞ = max_i |U_h(x_i) - U_exact(x_i)|
```

### 7.2 收敛阶的定义

当网格加密时，误差按幂律减小：

```
||E|| ≈ C · Δx^p
```

取对数：

```
log(||E||) ≈ log(C) + p · log(Δx)
```

p 即为收敛阶，可通过两组网格的误差计算：

```
p = log(||E_{h1}|| / ||E_{h2}||) / log(h1 / h2)
```

### 7.3 各格式的理论收敛阶

| 格式 | 光滑区 | 间断区 | 全局（含间断） |
|------|--------|--------|---------------|
| LF | 1 | 1 | 1 |
| LW | 2 | ~1 | ~1 |
| MC | 2 | ~1 | ~1 |
| Godunov | 1 | 1 | 1 |
| HLL | 1 | 1 | 1 |
| MUSCL-Hancock | 2 | 1 | ~1 |

**重要结论**：
在含间断的问题中，即使格式在光滑区是二阶的，全局收敛阶通常也退化为一阶。这是因为间断附近的误差（O(1)）主导了整体误差。

### 7.4 数值实验：验证收敛阶

**实验设计**：
1. 选择有精确解的问题（如干底Ritter解）
2. 固定物理参数和终止时间
3. 运行网格序列：nx = 50, 100, 200, 400, 800
4. 记录各格式的L1和L2误差
5. 绘制 log(误差) vs log(Δx) 图
6. 拟合斜率得到实验收敛阶

**期望结果**：
- 一阶格式：斜率 ≈ -1（即 p ≈ 1）
- 二阶格式（光滑区）：斜率 ≈ -2（即 p ≈ 2）

## 附录：公式速查表

### 浅水方程

```
守恒形式:  U_t + F_x = 0

U = [h, hu]ᵀ
F = [hu, hu² + gh²/2]ᵀ

Jacobian: A = [0, 1; gh-u², 2u]
特征值: λ₁ = u-c, λ₂ = u+c  (c = √(gh))
Riemann不变量: R± = u ± 2c
```

### Riemann问题

```
星区速度: u* = (u_L + u_R)/2 + (f_L(h*) - f_R(h*))/2

稀疏波函数: f_k(h) = 2(√(gh_k) - √(gh))   (h ≤ h_k)
激波函数:   f_k(h) = (h-h_k)√(g(h+h_k)/(2hh_k))  (h > h_k)

干底Ritter解:
  h = (2c_L - x/t)²/(9g),  u = 2(x/t + c_L)/3   (-c_L < x/t ≤ 2c_L)
```

### 数值通量

```
LF:   F_{i+1/2} = 1/2(F_i + F_{i+1}) - 1/2(Δx/Δt)(U_{i+1}-U_i)

LW:   U_{i+1/2}^{n+1/2} = 1/2(U_i+U_{i+1}) - Δt/(2Δx)(F_{i+1}-F_i)
      U_i^{n+1} = U_i^n - Δt/Δx(F_{i+1/2}^{n+1/2} - F_{i-1/2}^{n+1/2})

MC:   U_i^p = U_i^n - Δt/Δx(F_{i+1}^n - F_i^n)
      U_i^{n+1} = 1/2(U_i^n + U_i^p) - Δt/(2Δx)(F_i^p - F_{i-1}^p)

Godunov: F_{i+1/2} = F(U*(U_i, U_{i+1}))

HLL: F_{i+1/2} = (S_R F_L - S_L F_R + S_L S_R(U_R-U_L))/(S_R-S_L)

MUSCL: U_i^L = U_i - 1/2 Δx σ_i,  U_i^R = U_i + 1/2 Δx σ_i
       σ_i = minmod((U_i-U_{i-1})/Δx, (U_{i+1}-U_i)/Δx)
```

### 限制器

```
minmod:   φ(θ) = max(0, min(1, θ))
superbee: φ(θ) = max(0, min(2θ, 1), min(θ, 2))
van Leer: φ(θ) = (θ + |θ|)/(1 + |θ|)
```

### 误差与收敛阶

```
L1:  ||E||_1 = Δx Σ |U_h - U_exact|
L2:  ||E||_2 = √(Δx Σ |U_h - U_exact|²)
L∞: ||E||_∞ = max |U_h - U_exact|

收敛阶: p = log(E_{h1}/E_{h2}) / log(h1/h2)
```
